# 案例一（工业余热回收系统）蒙特卡洛不确定性分析报告

**作者**：郭京奥（Jingao Guo）

---

## 1. 分析目的

实训案例一的基准计算已与 US DOE 官方基准严格对齐（单位成本节约 $214.00、一次能源节约 7.58 MMBtu/ref、温室气体减排 818.69 lb CO2e/ref）。为了评估关键决策指标在输入参数存在不确定性时的稳健性，本报告对 `student_template.yaml` 中全部数值型输入参数施加 ±10% 扰动，采用蒙特卡洛方法进行 1000 次抽样分析。

## 2. 方法与假设

| 项目 | 设定 |
| :--- | :--- |
| 抽样次数 N | 1000 |
| 随机种子 | 42（可复现） |
| 输入参数范围 | 全部数值型输入参数（共 48 个） |
| 概率分布 | 三角分布（最小值 0.9×基准、最可能值 = 基准、最大值 1.1×基准） |
| 排除项 | `trl`（技术就绪度枚举常量，非数值型输入） |
| 计算引擎 | `TechTestFullEngine`（完整 TECHTEST 计算图网） |

> 说明：本分析采用分析者假定的 ±10% 上下界，而非对实测数据的经验分布拟合，用于对案例结论进行确定性敏感性检验。

## 3. 核心决策指标统计结果

| 核心指标 | 基准值 | 均值 | 标准差 | P5 | P50 | P95 |
| :--- | ---: | ---: | ---: | ---: | ---: | ---: |
| 单位成本节约 ($/ref) | 214.00 | 213.59 | 20.13 | 181.56 | 213.03 | 248.40 |
| 初级能耗节约 (MMBtu/ref) | 7.58 | 7.59 | 0.56 | 6.64 | 7.58 | 8.50 |
| 温室气体减排 (lb CO2e/ref) | 818.69 | 819.74 | 60.73 | 716.97 | 818.95 | 918.81 |
| 静态回收期 (年) | -11.87 | -12.07 | 1.87 | -15.39 | -11.87 | -9.26 |

**关键结论：**

1. **无系统性偏差**：所有指标的均值与基准值高度一致（偏差 < 1%），说明计算图网为线性/弱非线性关系，三角分布对称扰动下结果无偏。
2. **单位成本节约全为正值**：1000 次抽样中 `cost_savings_per_ref_volume > 0` 的次数为 **1000 / 1000**，即无论参数如何波动，新技术相较商业基准均可实现正的成本节约。
3. **投资回收期恒为负值**：P95 = -9.26 年、极大值为 -7.73 年，表明该技术在全部抽样情景下均具有显著投资回报，静态回收期稳健。
4. **节能与减排同样稳健**：一次能源节约与温室气体减排在 P5 分位仍然为正，说明余热回收系统在参数扰动下始终具备节能减排效益。

## 4. 不确定性对结论的影响

三个核心指标的变异系数（CV = 标准差 / 均值）约为：

- 单位成本节约：CV ≈ 9.4%
- 初级能耗节约：CV ≈ 7.4%
- 温室气体减排：CV ≈ 7.4%

上述变异主要来源于 CapEx（购置原值、寿命）、能耗单价与消耗量等直接参与成本/能耗/碳排核算的参数。尽管如此，指标的方向性结论（正节约、正减排）在完整 90% 置信区间（P5–P95）内均未发生逆转，说明案例一的决策结论具有较高稳健性。

## 6. 结论

在全部输入参数 ±10% 三角分布扰动的 1000 次蒙特卡洛模拟下，案例一（工业余热回收系统）的核心结论——正成本节约、显著节能与温室气体减排、负回收期——均保持稳定且未发生方向性逆转，模型结论对输入不确定性具有高度稳健性。
